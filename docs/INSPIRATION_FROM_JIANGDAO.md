## 一、原型里值得注意的东西

### 1. 主控台 = 成长总览 + 自适应推荐
- 五重段位：初境 / 知境 / 行境 / 精境 / 宗境，并直接显示「距知境 10 XP」。
- 精力管理四维：体能 / 情感 / 思维 / 意志，每项 100。
- 全程路径：角色走完整 9 章 + 训练的百分比、章节数、情境数与训练完成度。
- 自适应推荐：按长板（谋权 18）和短板（驭人 5）推荐「史鉴 / 训练 / 史鉴」三张卡，每张卡写明聚焦能力与子技能（如驭人·恩威并施）。
- 玩家决策风格标签：权谋型 / 稳健型等，直接进入报告与推荐。

### 2. 抉择页的「两难 + 展开详情 + 落子无悔」
- 每个情境先给一段有现场感的叙事，再给一句「两难」提炼，让玩家先理解矛盾再选。
- 三个选项默认只显示标题，点开后展开行动细节与风险标签（强势 / 立威 / 高风险）。
- 确认按钮用「落子无悔」替代普通「提交」，强化决策仪式感。
- 抉择页存在心力压力层（心力 12/50、连击门槛、激进选择可能加速崩溃），当前原型只是雏形，是否适合学习类产品需要实测。

### 3. 结果页三段式：后果 / 能力谱系 / 教练之眼
- 后果：一段剧情后果 + 决策定性（稳健抉择）。
- 能力谱系：+15 XP 与八维能力涨落，且细分到子技能（谋权·运筹帷幄 +6、沟通·化干戈为玉帛 -3）。
- 教练之眼：一句教练式追问（「你是在解决问题，还是在证明自己？」），并推荐一条历史镜鉴（资治通鉴·唐纪·太宗）。

### 4. 史鉴堂 / 经典堂：内容库变成可玩模块
- 史鉴堂：资治通鉴 64 个历史抉择时刻，每条按能力打标签（立信 / 心力 / 识人 / 决断 / 驭人 / 赏罚 / 谋权），一句话讲清事件与人物。
- 经典堂：权经九篇（求 / 争 / 用 / 掌 / 固 / 分 / 夺 / 让 / 弃权）、范蠡之道、毛选思想、情境高尔夫（90 天新官实战 · 六洞关卡）。
- 影视副线：约 200 部影视作品切片，按「沟通谈判 / 危机决策 / 心力淬炼」等主题分类，标注可玩。

### 5. 能力测评 = 三维六层 + 角色专属轨道
- 心性层 / 人际层 / 系统层三层框架。
- 三角色各自 5 个子维度：空降（识人·用人·驭人·谋权·固权）、创业（机会识别·资源整合·韧性坚持·商业敏感·愿景感召）、高潜（自驱力·敏捷迭代·跨界协同·影响力雏形·复盘自省）。
- 27 道情景判断题，每题 4 选项，即时反馈，能力追踪。

### 6. 三个在线/运营向模块
- AI 动态叙事：按玩家能力、历史与路线生成专属两难；默认聚焦最弱项；难度分入门 / 进阶 / 宗师。
- 多人协作 · 群策之堂：2-8 人一局、每局 3 个多人情境、4 位房间号、先各抒己见再共同复盘。
- 教练数据看板：学员列表（段位 / XP / 节数 / 入学日期）→ 学员详情（能力雷达、XP 成长曲线、八维变化趋势、教练洞察：强项 / 待精进 / 退步预警 / 能力均衡、最近 10 节选择历程）+ 对比分析。

## 二、当前《升维 / 权变之路》的现状对照

| 原型亮点 | 当前游戏现状 | 借鉴判断 |
| --- | --- | --- |
| 五重段位 + 距下一段 XP | 已有五段位（初阶观察者…执权者）与经验值，但主界面缺少「距下一段」的显性进度 | 直接补 UI，成本低 |
| 精力四维 | 单维精力资源（trialEnergy / 100）+ 情绪自愈能力 | 可做，但别再加一套并列能力模型 |
| 全程路径 / 自适应推荐 | 已有 90 天引领路线、教练提示、弱项提示 | 把推荐做成主控台首页三卡，成本低 |
| 两难 + 展开详情 + 落子无悔 | 已有情境、选项、专家反馈 | 补「两难」摘要与选项展开交互即可 |
| 结果页能力涨落 + 教练之眼 + 镜鉴 | 已有复盘、专家基准、教练提示 | 把三段式与历史镜鉴入口做进结果页 |
| 史鉴堂 / 经典堂 | 能力定义里有《权经》《资治通鉴》等出处，但没有独立可玩模块；存档仍残留 completedFilmQuests | 复用现有出处数据做轻量内容模块 |
| 影视副线 200 部 | 影视副线已下线，只有存档字段与旧文档 | 可考虑按模板重新上线，注意版权 |
| 角色专属测评轨道 | 已有 30 题能力基线测评 + 三角色选项集 | 把测评改成三角色专属子维度，信息量更直接 |
| AI 动态叙事 | 内容固定 + UGC 情境工坊 | 适合接服务端 LLM 生成，作为 P1 |
| 群策堂 2-8 人 | 已有 1v1 房间 / 自动匹配 / WebRTC | 服务端协议可扩展，作为 P1 |
| 教练数据看板 | 已有教练端批量导出（coach:export）、教练工作坊、报告导出 | 缺在线看板，作为 P1 |
| 性别视角 | 只有角色视角，无性别叙事变体 | P2 打磨项 |

## 三、建议的落地优先级

### P0：先用小成本把「成长感」补满
1. 主控台加「五重段位进度条 + 距下一段 XP + 全程路径」，放在地图旁。
2. 结果页改成「后果 → 能力涨落（细分到子技能）→ 教练之眼 → 历史镜鉴」四段式，镜鉴先复用现有《权经》《资治通鉴》出处做成轻量卡。
3. 能力测评加三角色专属轨道（沿用现有 10 能力，不要另建能力体系）：空降 / 创业 / 高潜各 5 个子维度，测评结果直接映射到现有能力与 90 天路线。
4. 主控台自适应推荐三卡：按长板/短板推荐「主线情境 / 训练营 / 史鉴卡」，每张卡写清聚焦能力与子技能。

### P1：做差异化运营能力
5. AI 动态叙事：在服务端加 LLM 生成接口，输入玩家档案 + 最弱能力 + 难度，输出结构化情境（走现有 StoryNode schema 校验），失败时回退本地模板。
6. 教练数据看板：把现有云存档、排行榜、analytics payload 扩展成学员列表 + 能力雷达 + XP 曲线 + 趋势 + 洞察 + 对比分析。
7. 群策堂：把房间服务从 1v1 扩展成 2-8 人，每局 3 个多人情境，回合后展示分布并进入群体复盘。

### P2：主题与体验打磨
8. 建档加名号 + 男性/女性视角，存档记录视角字段，只影响少量叙事细节。
9. 精力四维化（体能 / 情感 / 思维 / 意志）之前先做一次真机测试，确认不会和现有 10 能力、五维模型、团队学院四维造成新的认知分裂。
10. 心力压力 / 连击节律这类机制先小范围试玩验证，学习类产品要防止变成「测反应速度」。

## 四、别照搬的地方
- 原型的三角色轨道各有 5 个不同维度，和八维/十维是两套语言；当前游戏已有「三套能力模型导致认知分裂」的历史教训，因此只把角色轨道当作测评子维度，主模型仍用现有 10 能力。
- 200 部影视切片涉及版权与片名使用，商用前需要确认授权边界；内部培训场景可以先用。
- 教练看板收集学员数据前需要隐私告知与数据最小化设计。
