# 主线情境扩展参考来源

2026-08-10 从 GitHub 检索同类项目后，将以下情境模式吸收进主线扩展情境（每章 9 个，共 81 个）。

## 参考项目

- `dastergon/wheel-of-misfortune`：值班事故模拟。启发「值班事故」情境：先止血、后复盘，避免在恢复前追责。
- `SamirSaad786/the-hire-wire`：限预算挑人组建团队。启发「人选组合」情境：可见特质与隐藏短板、预算约束、九个月结果回看。
- `EthiQuest/EthiQuest-AI-Dilemma-Game`：伦理两难决策。启发「伦理两难」情境：灰色要求、合规与业绩冲突、伦理画像。
- `Harsh-141cmd/Crisis-Management-Game`：企业危机沟通模拟。启发「危机通报」情境：内部与外部同时扩散、统一口径、利益相关者管理。
- `prabapro/decision-lab`：限时团队领导力决策模拟。启发「历史案例」情境：有限资源、时间压力、经典管理案例同构。
- `open-risk/FuriousBanker`：金融风险教育严肃游戏。启发「风险敞口」情境：异常指标被“正常”标签掩盖、何时把风险摆上台面。
- `EZEKNARCELLES/LeadershipChallenge`：领导者时间管理场景。启发「优先级抉择」情境：多事项同时到期、按“不做哪件损失最大”排序。

## 使用原则

- 只参考项目的情境结构与决策模式，不复制原仓库的文案、代码或受版权保护的内容。
- 每个扩展情境都保持职场与管理语境，并复用游戏已有的选项机制、能力成长与资源系统。
- 新增内容进入 `src/core/mainScenarios.ts`，由 `story.ts` 合并进主线节点，英文翻译与角色视角同步补齐。
