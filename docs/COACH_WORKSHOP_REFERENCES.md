# 教练工作坊重构参考

2026-08-10 从 GitHub 检索教练/反馈/工作坊类项目后，重构了「教练工作坊」：先为线上玩家生成个人教练卡，再保留教练/培训师使用的小组工作坊模式。

## 参考项目

- `WieSoe/feedback-coach`：反馈准备工具，支持 SBI、非暴力沟通、SCARF 等框架。启发个人教练卡的结构：先把玩家自己的存档变成“结构化反馈”，再给可执行计划。
- `thermondo/threesixty`：360 度反馈工具。启发“能力强弱 + 决策风格 + 错过的好棋”多视角呈现，避免只给一个总分。
- 综合「行动承诺 / 未来 30 天」工作坊惯例：把教练结论落到 3 个具体动作，而不是只展示统计。

## 落地方式

- 新增 `CoachWorkshopEngine.generatePersonalReport(save)`：基于玩家自己的存档生成优势、聚焦能力、决策风格、错过的关键选择和 30 天行动计划。
- 教练页顶部新增「我的教练卡」，玩家无需导入任何数据即可看到对自己有用的下一步，并可一键进入训练、报告或 1v1。
- 原导入/演示功能保留为「小组工作坊模式（教练 / 培训师用）」，避免和玩家个人体验混在一起。
