# 团队管理训练营 · 内容与逻辑审查报告

日期：2026-08-13  
范围：`src/core/team-academy.ts`、`src/core/academy-scenarios.ts`、三套角色情境数据、训练营 UI、自动化测试与 CI。

## 审查发现的问题

### P0 内容与路径

1. **情境过短**：108 个情境的 `situation` 只有 15-31 字，`feedback` 只有 12-28 字，属于要点式摘要，无法承载“教会玩家、可落地”的目标。
2. **最佳答案严重失衡**：108 个情境中 106 个的 `best` 都是第 2 个选项，训练变成“永远选第二项”，路径设计失效。
3. **没有逐选项路径**：无论玩家选对还是选错，看到的都是同一句反馈，不知道“我选的这条路会发生什么、为什么不好、怎么补救”，最优路径也没有被揭示。

### P1 逻辑与防刷分

4. **情境可重复刷分**：反复进入同一情境选正确项，`scenarioScores` 会无限累加。
5. **练习题可重复刷分**：`practiceScores` 同样可以靠重复作答累加。
6. **作业可重复加维度**：同一课作业反复提交会重复叠加四维成长值。
7. **导师可重复招募**：换不同导师可反复获得 +8 维度奖励。

### P2 教学闭环

8. 课程缺少可执行的“本周落地清单”，学了模型但没有回家动作。
9. 跨角色存在重复标题（如“培养接班人”“授权后犯错”），内容边界不清晰。
10. 未完成的关卡卡片显示 `0 分`，容易误解为已作答。

## 本轮迭代

### 内容重写

- 108 个情境全部重写：`situation` 扩展到 2-4 句、带具体人物/数字/时间/利害关系；`feedback` 升级为教学原则；`knowledge` 保留为知识点索引。
- 每个情境新增 `paths[4]`，逐条包含 `outcome`（结果）、`why`（原因）、`recovery`（补救），共 432 条路径说明。
- 最佳答案重新分布：全库 0/1/2/3 档分布为 26/29/27/26，各档均不少于 6 个，杜绝套路化。
- 跨角色重复标题去重，108 个标题全局唯一。
- 27 节课新增 5 条“落地清单”，对应每周可执行动作，课程页第 6 步展示。

### 逻辑修复

- 情境与练习题只在“首次答对”时加分，重复作答不再刷分。
- 作业通过后重复提交不再重复叠加维度成长。
- 每次训练只能招募一位导师，重复招募无效。
- 情境页新增：所选项的结果/原因/补救、最优路径与依据、知识点、下一情境。
- 未开始的情境卡片显示“未开始”，不再显示误导性的 `0 分`。

### 自动化门禁

- 新增 `scripts/team-academy-audit.mjs` 与 `npm run test:academy`：
  - 108 个情境、唯一 ID、唯一标题；
  - 每情境 4 选项、4 条路径、路径内容非空；
  - 最佳答案分布均衡；
  - 每角色 9 关 × 4 情境，课程覆盖全部情境 ID；
  - 每课 5 条落地清单、练习答案合法；
  - 情境关卡与课程编号对齐。
- 该门禁已加入 GitHub Actions `test` 任务。

## 验证结果

- `npm run test:academy`：PASS，108 情境、432 路径、27 课清单。
- `npm run test:unit`：PASS，含防刷分、路径返回、作业/导师单次计分断言。
- `npm run build`：PASS。
