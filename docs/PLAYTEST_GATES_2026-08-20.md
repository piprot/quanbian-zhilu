# P2 试玩门槛：精力四维与心力压力

> 2026-08-20 按 P0/P1/P2 清单落地时的两条 P2 门槛。精力四维已以「派生展示」上线，心力压力/连击节律暂不实现，先用试玩验证再决定是否进入数值层。

## 1. 精力四维

当前状态：
- 已在主控台侧栏新增「精力管理 · 四维」派生面板：体能 / 情感 / 思维 / 意志。
- 数值由现有资源与能力派生（energy/trust/influence/capital + 情绪自愈/协同沟通/结构思考/执行力等），不写入存档，不替换现有单维精力资源。

试玩门槛（通过后才允许把四维写进游戏数值）：
1. 5 位真实用户各完成 1 个完整章节。
2. 每位用户能用自己的话解释「刚才哪个维度影响了我的判断」，而不是只复述四个词。
3. 访谈中不出现与十项能力、领导力五维、团队学院四维混淆的表述。
4. 移动端 390px 下四维面板无横向溢出，读屏可逐项朗读。

若不满足：保持派生展示，不进入资源结算。

## 2. 心力压力 / 连击节律

参考原型「将道」的心力交瘁（12/50）与连击门槛机制，本版本不实现，避免学习产品变成反应速度测试。

试玩门槛（通过后才进入实现）：
1. 5 位用户各完成 3 个带计时/压力的情境。
2. 自评压力得分不高于无压力组基准；「紧张但可控」比例 ≥ 80%。
3. 专家判断准确率不低于无压力对照组。
4. 用户反馈里「压力感来自情境后果」的数量 ≥「压力感来自倒计时」的数量。
5. 通过后默认关闭，设置页提供独立开关，并尊重 `prefers-reduced-motion`。
