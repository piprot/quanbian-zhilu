# 真实用户测试工具包

状态：2026-08-11。用于补齐 `docs/FINAL_ACCEPTANCE_2026-08-11.md` 中“仍需外部环境完成”的真实用户验证。目标是在 3-5 位真实高管 / 教练身上完成一章主线 + 1v1 体验，并记录停顿点与困惑点。

## 测试对象

- 3-5 位目标用户：中层管理者、高潜人才、高管教练或企业培训师。
- 每位用户至少完成：创建档案 → 第一章 2 个决策 → 1 次 1v1 → 查看复盘。
- 可选：教练用户额外体验情境工坊和实时推演。

## 测试环境

- 线上地址：https://piprot.github.io/quanbian-zhilu/
- 版本：1.7.30
- 设备：桌面优先（Chrome / Edge），有条件时补充 iPhone Safari 与 Android Chrome。
- 准备：浏览器无痕窗口、录屏工具、记事本记录停顿点。

## 60 分钟测试脚本

### 1. 首屏印象（5 分钟）

- 不做任何提示，让用户自己描述“这是一个什么产品、我下一步该做什么”。
- 记录：第一次点击位置、犹豫时间、是否误读按钮。

### 2. 建档与测评（10 分钟）

- 点击「创建档案」，选择角色并命名。
- 允许跳过测评，也可以完成前 5 题后跳过。
- 记录：选项是否可理解、能力基线报告是否有价值、是否觉得信息过载。

### 3. 第一章主线（15 分钟）

- 进入主线，完成第一章前 2 个情境决策。
- 观察：用户是否理解专家 / 部分 / 高风险反馈；是否展开「六段式复盘」；是否理解资源变化。
- 记录：最困惑的文案、最想获得的额外信息、是否愿意继续玩下一章。

### 4. 1v1 与领导力游戏（10 分钟）

- 完成一次 AI 1v1，至少 3 回合。
- 再选一个领导力小游戏（建议决策棋或危机指挥）。
- 记录：预判 / 风格押注是否可理解；小游戏教学是否够清楚；是否有明显挫败点。

### 5. 复盘与复习（10 分钟）

- 打开复盘报告，查看能力雷达、教练追问、间隔复习与按能力复习看板。
- 如果已有错选，尝试「双轴回练」。
- 记录：报告中最有用 / 最没用的部分。

### 6. 教练端（仅教练用户，10 分钟）

- 打开教练工作坊，载入演示小组或导入真实存档。
- 体验「实时情境推演」：创建会话、添加 2-3 名学员、揭示分布并与专家基准对比。
- 记录：这个功能能否用于真实工作坊，还缺什么。

## 反馈表单

请为每项打 1-5 分并给出理由：

用户也可以直接在游戏内「设置 → 体验反馈」选择评分并填写反馈，一键生成包含版本、角色、能力与通关进度的结构化文本并复制，再粘贴到本表单回传。

1. 首屏是否立刻知道“这是什么、下一步做什么”？
2. 决策反馈是否帮助理解领导力原则？
3. 六段式复盘是否让学习更深入？
4. 1v1 和小游戏是否值得反复玩？
5. 报告和间隔复习是否对真实成长有用？
6. 教练工作坊是否可实际用于团队培训？
7. 你会在什么场景使用这款产品？
8. 最想删除 / 最想增加的功能是什么？

## 完成标准

- 新玩家无外部指导也能独立完成第一章前 2 个决策。
- 用户能说出至少 1 条可迁移到现实工作的领导力原则。
- 用户愿意继续玩或愿意推荐给同事。
- 全程无崩溃、无卡死、无横向溢出；控制台无报错。
- 教练用户认可实时推演可用于小组工作坊，或给出可执行修改建议。
