# 领导力多维模型设计参考

状态：2026-08-11。将「信服力 / 共情力 / 决断力 / 格局力 / 韧性值」五维模型融入主线能力、试炼、档案与士气系统。

## 参照项目

### 1. arayaconsulting/Araya-Leadership-Screening-Tool
- 地址：https://github.com/arayaconsulting/Araya-Leadership-Screening-Tool
- 模式：基于 John C. Maxwell 五级领导力模型做的筛选工具。
- 借鉴点：把领导力拆成可测评、可增长的分层维度，而不是单一分数。

### 2. prabapro/decision-lab
- 地址：https://github.com/prabapro/decision-lab
- 模式：领导力情境决策模拟，每个选择都有评分与复盘。
- 借鉴点：用真实情境承载抽象领导力维度，让成长发生在选择中。

### 3. rbundock/executive-evasion
- 地址：https://github.com/rbundock/executive-evasion
- 模式：浏览器高管压力模拟。
- 借鉴点：韧性/士气适合用“困境选择”呈现，玩家要在压力中做取舍。

## 本仓映射

- 信服力：根基 · 尊重，靠以身作则、诚信决策增长；映射 authority / stability / structure。
- 共情力：亲和 · 增值 · 吸引力，靠关怀团队、有效沟通增长；映射 communication / insight。
- 决断力：导航 · 优先次序 · 时机，靠做对的事、把控方向增长；映射 strategy / execution。
- 格局力：授权 · 爆炸性倍增 · 传承，靠培养他人、授权放权增长；映射 deploy / mobilize。
- 韧性值：制胜 · 动势 · 舍得，在困境选择中波动，影响士气；映射 recovery。
- 新增 5 个五维试炼关卡，通关分别奖励对应维度经验；所有试炼答案会改变士气，韧性试炼专门训练困境中的取舍。
